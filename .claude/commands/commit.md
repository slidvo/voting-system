Посмотри какие файлы изменились через git status && git diff.
Если изменения относятся к разным частям проекта — сгруппируй их и сделай несколько коммитов.
Для каждой группы составь осмысленное название на английском в стиле conventional commits (feat:, fix:, chore: и т.д.).
Сделай git add и git commit для каждой группы отдельно.
